# Planted cases

Each subdirectory is one case: `tip.txt`, `ledger.csv`, `vendors.csv`, `staff.csv`, `case.json` (format in `docs/contract.md` section 8). Generated by `cases/gen.py` with a seed; design in `docs/dataset-design.md`.

| case | plants | expected |
| --- | --- | --- |
| `career_overlap` | approver's Crustdata employment at the vendor ends 3 months before first payment | conflict_of_interest Substantiated |
| `shell_vendor` | vendor shares address and phone with a staff member; created 8 days before first invoice; round amounts under the limit; no Crustdata record | shell_company Substantiated |
| `false_lead` | tip names a staff member who shares a name with a real former employee of the vendor | conflict_of_interest Unfounded |
| `duplicate_billing` | same invoice number and amount paid twice through a large real vendor | duplicate_billing Substantiated; vendor itself not shell |
| `clean_controls` | large real vendors, normal patterns, no graph path | all must_clear, no Substantiated |
| `shared_office_honest` | two unrelated real vendors at one coworking address, nothing else shared | both must_clear; shell hypotheses end Unfounded or Unsubstantiated |

The held-out case (different seed and names) lives outside the repo until the recording.
